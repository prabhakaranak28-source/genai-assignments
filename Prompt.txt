## 🔹 Test Case Reviewer Prompt Template

### **Instruction**

You are required to review a given software test case and evaluate its quality.
Analyze the test case based on completeness, clarity, structure, and adherence to testing best practices.
Identify issues, suggest improvements, and provide an enhanced version of the test case.

---

### **Context**

The input provided is a software test case that may contain missing steps, unclear instructions, poor structure, or lack of validation points.
A high-quality test case should include:

* Clear and descriptive title
* Preconditions
* Test steps with proper sequencing
* Expected results for each step
* Test data (if applicable)
* Postconditions (if applicable)

---

### **Example**

**Input Test Case:**

```
Title: Login Test

Steps:
1. Open website
2. Enter username and password
3. Click login

Expected Result:
User logs in
```

**Output:**

```
Issues:
- Title is too generic
- Missing preconditions
- Steps lack detail
- Expected result is vague

Suggestions:
- Use a more descriptive title
- Add preconditions (e.g., user account exists)
- Specify input values and actions clearly
- Define precise expected results

Improved Test Case:
Title: Verify successful login with valid credentials

Preconditions:
- User account is registered and active
- User is on login page

Steps:
1. Navigate to the login page
2. Enter valid username in the username field
3. Enter valid password in the password field
4. Click on the login button

Expected Results:
- User is successfully authenticated
- User is redirected to the dashboard
- Welcome message is displayed
```
